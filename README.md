# The Man Who Walked Away From the Cross

A research article by Setvin Noether examining the swoon hypothesis, the psychology of ego death, the divergence between the canonical Gospels and the Gospel of Thomas, Deism, translation variance, archaeology, and the Kashmir migration tradition — arguing that Jesus survived crucifixion and that scripture itself records the psychological aftermath. Built as a single-page stained-glass themed site with full SEO, structured data, and a favicon set cropped from the article's own hero artwork.

Read it here: **[Ego Death](https://sauerninja.github.io/Ego-Death/)**

~150 minute read.

## Files

- `index.html` — the article (all CSS/JS inline)
- `hero.png` — hero artwork (public-domain Renaissance painting, Christ carrying the cross)
- `og-image.png` — social share image
- `favicon.ico`, `favicon-16.png`, `favicon-32.png`, `favicon-192.png`, `favicon-512.png`, `apple-touch-icon.png` — favicon set, cropped from the hero art
- `404.html` — themed not-found page
- `robots.txt`, `sitemap.xml`, `.nojekyll` — site config
